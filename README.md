# Tourism Website - Explore Beautiful Indian Destinations

A professional, responsive static website showcasing popular tourist destinations across India. This project demonstrates modern web development practices with semantic HTML, professional CSS styling, and interactive JavaScript functionality.

## 🎯 Features

- **Fully Responsive Design** - Optimized for desktop, tablet, and mobile devices
- **Modern UI/UX** - Professional styling with smooth animations and transitions
- **Image Carousels** - Interactive image galleries for each destination
- **Smooth Navigation** - Seamless section transitions with scroll effects
- **Professional Typography** - Carefully selected fonts and spacing
- **Accessibility Features** - Semantic HTML5 and proper ARIA labels
- **Cross-browser Compatible** - Works on Chrome, Firefox, Safari, Edge
- **Performance Optimized** - Fast loading with optimized background images

## 🚀 Getting Started

### Prerequisites
- Any modern web browser (Chrome, Firefox, Safari, Edge)
- No server or installation required

### Installation & Running

1. **Clone or Download** the repository:
   ```bash
   git clone https://github.com/harishm1823/Building-Static-Website.git
   cd Building-Static-Website
   ```

2. **Open in Browser**:
   - **Option A**: Double-click `index.html` in the file explorer
   - **Option B**: Right-click `index.html` → Open with → Choose your browser
   - **Option C**: Drag and drop `index.html` into your browser window

3. **View Online** (if deployed):
   - Open the hosted URL in your browser

## 🔧 Customization

### Changing Colors
Edit the color values in `index.css`:
```css
/* Primary color */
background-color: #25b1cc;

/* Secondary color */
color: #0f0e46;
```

### Adding New Destinations
1. Add a new section in `index.html`
2. Create corresponding CSS classes in `index.css`
3. Add carousel and details following the existing pattern
4. Link from the favorites section

### Modifying Fonts
Update the `@import` statement at the top of `index.css` to use different Google Fonts.

## 🐛 Troubleshooting

**Q: Images not loading?**
- Check internet connection (images are from CDN)
- Verify browser allows external resources

**Q: Carousel not working?**
- Ensure Bootstrap and jQuery are loaded
- Check browser console for errors

**Q: Styling looks broken?**
- Clear browser cache (Ctrl+Shift+Delete)
- Ensure CSS file is in the same directory
- Check file path in HTML
