# Building Static Website

## Description
A responsive static website built using HTML, CSS, JavaScript, and Bootstrap.

## Features
- Responsive design
- Mobile-friendly layout
- Modern user interface
- Cross-browser compatibility

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap

## How to Run

1. Download or clone this repository:
   ```bash
   git clone https://github.com/harishm1823/Building-Static-Website.git
   ```

2. Open the project folder.

3. Double-click `index.html` or open it in any modern web browser (Chrome, Edge, Firefox, etc.).
