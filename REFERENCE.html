🔧 JavaScript Functions

display(sectionId)

function display(sectionId) {
  // Hide all sections
  // Show selected section
  // Scroll to top smoothly
}

Usage: <button onclick="display('sectionFavouritePlaces')">

Add new sections with a unique ID, then call display() with that ID to navigate.
